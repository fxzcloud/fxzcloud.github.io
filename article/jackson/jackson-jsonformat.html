                                                          # jackson-jsonformat

                                                          # 1. 概述

                                                          在本教程中，我们将了解如何在 Jackson 中使用*@JsonFormat*。

                                                          @JsonFormat是 Jackson 注解，它允许我们配置属性值的序列化或反序列化方式。例如，我们可以指定如何根据SimpleDateFormat格式设置date和Calendar的格式。

                                                          # 2.Maven依赖

                                                          @JsonFormat是在jackson-databindopen in new window包中定义的，所以我们需要以下Maven依赖：

                                                          <dependency>
    <groupId>com.fasterxml.jackson.core</groupId>
    <artifactId>jackson-databind</artifactId>
    <version>2.13.3</version>
</dependency>

                                                          # 3. 入门

                                                          # 3.1.使用默认格式

                                                          我们将首先演示将@JsonFormat注解与类一起使用的概念。

                                                          由于我们想要解释注解的详细信息，因此将根据请求创建User对象（而不是从数据库存储或加载）并序列化为 JSON：

                                                          public class User {
    private String firstName;
    private String lastName;
    private Date createdDate = new Date();

    // standard constructor, setters and getters
}

                                                          构建并运行此代码示例将返回以下输出：

                                                          {"firstName":"John","lastName":"Smith","createdDate":1482047026009}

                                                          正如我们所看到的，createdDate字段显示为自纪元以来的毫秒数，这是日期字段使用的默认格式。

                                                          # 3.2.在 Getter 上使用注解

                                                          我们现在将使用*@JsonFormat指定序列化createdDate*字段的格式。

                                                          让我们看看针对此更改更新的 User 类。我们对createdDate字段进行注解，如图所示，以指定日期格式。

                                                          用于*模式参数的数据格式由SimpleDateFormatopen in new window*指定：

                                                          @JsonFormat(shape = JsonFormat.Shape.STRING, pattern = "yyyy-MM-dd@HH:mm:ss.SSSZ")
private Date createdDate;

                                                          完成此更改后，我们再次构建项目并运行它。

                                                          这是输出：

                                                          {"firstName":"John","lastName":"Smith","createdDate":"2016-12-18@07:53:34.740+0000"}

                                                          在这里，我们使用*@JsonFormat注解使用指定的SimpleDateFormat格式来格式化createdDate*字段。

                                                          上面的示例演示了在字段上使用注解。我们还可以在 getter 方法（属性）中使用它。

                                                          例如，我们可能有一个在调用时计算的属性。在这种情况下，我们可以在 getter 方法上使用注解。

                                                          请注意，我们还更改了模式以仅返回即时的日期部分：

                                                          @JsonFormat(shape = JsonFormat.Shape.STRING, pattern = "yyyy-MM-dd")
public Date getCurrentDate() {
    return new Date();
}

                                                          这是输出：

                                                          { ... , "currentDate":"2016-12-18", ...}

                                                          # 3.3.指定时区

                                                          除了指定日期格式之外，我们还可以指定序列化的时区设置。

                                                          不指定此参数会导致使用默认区域设置执行序列化：

                                                          @JsonFormat(
  shape = JsonFormat.Shape.STRING, pattern = "yyyy-MM-dd@HH:mm:ss.SSSZ", locale = "en_GB")
public Date getCurrentDate() {
    return new Date();
}

                                                          # 3.4.指定Shape

                                                          使用*@JsonFormat并将Shape设置为JsonFormat.Shape.NUMBER会导致Date类型的默认输出- 作为自 epoch 以来的毫秒数。*

                                                          参数模式不适用于这种情况并被忽略：

                                                          @JsonFormat(shape = JsonFormat.Shape.NUMBER)
public Date getDateNum() {
    return new Date();
}

                                                          让我们看看输出：

                                                          { ..., "dateNum":1482054723876 }

                                                          # 4. 不区分大小写的反序列化

                                                          有时，我们从各种来源收到 JSON 文档，它们在属性名称中不遵循相同的字母大小写规则。

                                                          例如，一个 JSON 文档具有*“firstname”: “John”，但其他文档可能包含“firstName”: “John”* 或*“FIRSTNAME”: “John”。*

                                                          默认的反序列化器无法自动识别不同字母大小写的属性名称。让我们通过一个例子快速理解这个问题。

                                                          首先，假设我们有一个 JSON 文档作为输入：

                                                          static final String JSON_STRING = "{\"FIRSTNAME\":\"John\",\"lastname\":\"Smith\",\"cReAtEdDaTe\":\"2016-12-18@07:53:34.740+0000\"}";

                                                          *我们可以看到， “FIRSTNAME”、“lastname”和“cReAtEdDaTe”*这三个属性遵循完全不同的字母大小写规则。现在，如果我们将此 JSON 文档反序列化为User对象，将引发UnrecognizedPropertyException ：

                                                          assertThatThrownBy(() -> new ObjectMapper().readValue(JSON_STRING, User.class)).isInstanceOf(UnrecognizedPropertyException.class);

                                                          为了解决这类问题，我们必须让我们的反序列化器执行不区分大小写的反序列化。接下来，让我们探讨如何使用*@JsonFormat*注解来实现这一点。

                                                          **@JsonFormat注解允许我们通过with属性设置一组JsonFormat.Featureopen in new window**值：@JsonFormat(with = JsonFormat.Feature … )。

                                                          此外，JsonFormat.Feature 是一个枚举。它预定义了一组选项来指定属性序列化或反序列化行为。

                                                          ACCEPT_CASE_INSENSITIVE_PROPERTIES功能告诉解串器不区分大小写地匹配属性名称。要使用此功能，我们可以将其包含在类级@JsonFormat注解中。

                                                          接下来，让我们使用此注解和功能创建一个UserIgnoreCase类：

                                                          @JsonFormat(with = JsonFormat.Feature.ACCEPT_CASE_INSENSITIVE_PROPERTIES)
class UserIgnoreCase {
    private String firstName;
    private String lastName;

    @JsonFormat(shape = JsonFormat.Shape.STRING, pattern = "yyyy-MM-dd@HH:mm:ss.SSSZ")
    private Date createdDate;

    // the rest is the same as the User class
    ...
};

                                                          现在，如果我们将 JSON 输入反序列化为*UserIgnoreCase，*它将按预期工作：

                                                          UserIgnoreCase result = new ObjectMapper().readValue(JSON_STRING, UserIgnoreCase.class);
SimpleDateFormat fmt = new SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSSzz");
Date expectedDate = fmt.parse("2016-12-18T07:53:34.740+0000");
assertThat(result)
  .isNotNull()
  .returns("John", from(UserIgnoreCase::getFirstName))
  .returns("Smith", from(UserIgnoreCase::getLastName))
  .returns(expectedDate, from(UserIgnoreCase::getCreatedDate));

                                                          # 5. 结论

                                                          综上所述，我们使用*@JsonFormat来控制Date和*Calendar类型的输出格式。
